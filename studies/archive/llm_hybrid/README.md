# Archived LLM hybrid evidence

**ARCHIVE_ONLY / PARTIAL**, not a canonical benchmark. See
[legacy history](../../../docs/archive/LLM_HYBRID_LEGACY_HISTORY.md).

`relocation_manifest.json` resolves all historical paths to byte-identical retained
files. Exact duplicates are stored once. Original absolute/relative path strings
inside frozen protocols are unchanged. Some binaries are local-only, as before;
the `tracked` flag distinguishes what the archive tag can recover.
